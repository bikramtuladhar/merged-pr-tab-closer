# Privacy Policy: Merged PR Tab Closer for GitHub

_Last updated: November 24, 2026_

Merged PR Tab Closer for GitHub does not collect, store, sell or send any personal data or browsing data.

**What the extension does on your computer**
- It reads the page of open `github.com` pull request tabs, only to check whether the pull request has been merged.
- It moves merged pull request tabs into a tab group and closes them when you click the toolbar icon.

**What it does not do**
- It makes no network requests of its own and has no servers.
- It doesn't use analytics, tracking or advertising.
- It doesn't read pages on any site other than github.com.
- It doesn't save any data, not even settings.

**Contact**
Questions about this policy: open an issue at https://github.com/bikramtuladhar/merged-pr-tab-closer/issues
